## About the Project

ShopSphere is an e-commerce shopping web application and desktop inventory management system built using:
* Java Servlets 6.1 & JSP 3.1
* Apache Tomcat 11
* MySQL 8.x
* Java Swing (MVC Desktop Inventory Viewer)
* Apache Maven

## Batch Scripts in this Folder

* **`quick_start.bat`** - Interactive menu to launch the web app, set up the database, or start the desktop viewer.
* **`setup_database.bat`** - Imports `ShopSphere/database/shopsphere.sql` into MySQL.
* **`start_tomcat.bat`** - Builds the WAR file and launches Apache Tomcat.
* **`run_desktop_swing.bat`** - Runs the Swing desktop inventory app.
