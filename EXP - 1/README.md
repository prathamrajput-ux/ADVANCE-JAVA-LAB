# Advanced Java Lab Repository

This repository contains Java lab projects for advanced Java coursework, including a Student Registration GUI and a Calculator application using Swing.

## Contents
* `StudentRegistration.java` — Java Swing application for registering student details with form validation and confirmation dialog.
* `CALCULATOR/` — Folder containing a simple Swing-based calculator with addition, subtraction, multiplication, and division.

## Features
* **Student Registration:** Form fields, validation checks, reset button, and formatted submission confirmation.
* **Calculator App:** GUI with numeric input, operation buttons, result display, and error handling for invalid input and division by zero.

## Requirements
* Java Development Kit (JDK 8 or higher)
* A Java IDE or command-line environment for compiling and running Java files.

## How to Run

### Run the Student Registration App
1. Open a terminal in the repository root.
2. Compile:
   ```bash
   javac StudentRegistration.java
   ```
3. Run:
   ```bash
   java StudentRegistration
   ```

### Run the Calculator App
1. Open a terminal in the `CALCULATOR` folder.
2. Compile all calculator files:
   ```bash
   javac *.java
   ```
3. Run:
   ```bash
   java RunCalculator
   ```
